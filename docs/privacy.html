Privacy Notice

Beta notice · Updated 30 September 2026

This notice explains how the current Dentora beta handles study prompts, chat history, and PDF uploads.

What the browser stores

Recent chats and a random browser session identifier are stored in your browser's local storage. They are not currently synced to a Dentora account. Clearing browser data or using another device may remove access to that local history.

What the backend processes

When you ask a question, the prompt is sent to the Dentora backend. Relevant textbook or uploaded-PDF excerpts may be included in a model request so that Dentora can generate a source-aware answer.

Temporary PDF Tutor uploads

PDF Tutor uploads are processed for the current browser session. The original temporary PDF is not intentionally stored as a permanent file by Dentora. Extracted temporary session content is held in server memory and is automatically expired after a limited period; using the Remove PDF control also asks the backend to clear that session copy.

AI and infrastructure providers

Dentora uses external infrastructure and AI providers. Prompts and the limited excerpts needed to answer them may be processed by the configured providers. Hosting and AI providers may maintain their own security and operational logs under their respective policies.

Permanent study library

Dentora also has an administrator-managed retrieval library used to support cited study answers. Ordinary PDF Tutor uploads are not automatically added to this permanent library.

Do not upload sensitive information

Do not upload patient records, personally identifiable clinical information, passwords, financial information, or other sensitive data. Dentora is an educational study tool, not a system for storing patient information.

Private beta access

The current beta uses a shared invite code for approved testers. The code is stored in browser session storage so it is cleared when the browser session ends. It is separate from the administrator key used to manage the permanent library.

Answer feedback

If you use the Report wrong answer control, Dentora may temporarily retain the reported question, answer, source summary, and your feedback reason so the developer can review the problem. Do not include patient-identifying or other sensitive information in a report.

Accounts and payments

The current beta does not provide Dentora user accounts or collect payment details through the app.
